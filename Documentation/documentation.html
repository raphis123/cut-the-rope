Product Overview

Cut the Rope is a browser-based physics puzzle game inspired by the classic rope-cutting genre. Swipe across ropes to drop the candy into the mouth of Momo, collect stars, and complete 100 handcrafted levels across 10 themed worlds.

100 Levels Procedural + hand-tuned stages with increasing difficulty
Realistic Ropes Verlet physics with swing, sag, and multi-rope puzzles
Rich Gameplay Ice, spikes, bubbles, wind, bounce pads & moving platforms
Mobile Ready Touch controls, performance scaling for weak devices
Full UI Loading screen, menu, level select, pause, win/lose overlays
Audio System Procedural music & SFX via Web Audio API
Animated Character Momo — procedural draw with eat, sad & idle animations
Reskin Ready Swap sprites, edit levels, restyle CSS without a build step

Technology

  • Vanilla HTML5, CSS3, and JavaScript — no framework required
  • Canvas 2D renderer with optional image sprite swap
  • Progress saved in localStorage
  • Works fully offline — all assets bundled locally (fonts, scripts, styles)

Installation & Running

Quick Start (Local)

  1. Unzip the product folder to any location on your computer.
  2. Open index.html in a modern browser (Chrome, Firefox, Safari, Edge).
  3. Tap Tap to Start! on the loading screen, then play from the main menu.
For best audio behaviour, interact with the page once (tap/click) so the browser unlocks sound.

Offline Play

The entire project is self-contained. No internet connection is required after download. All fonts are stored in fonts/ and all scripts/styles load from local files. Open index.html directly or host the folder on any static server.

Web Server (Recommended for Production)

Host the entire folder on any static host (Netlify, GitHub Pages, Apache, Nginx, etc.):

your-site.com/cut-the-rope/index.html

No server-side code or database is required.

Mobile / PWA

The game includes mobile viewport meta tags and touch-action settings. Add to home screen on iOS/Android for an app-like experience.

How to Play

Goal

Cut the rope(s) so the candy falls into Momo's mouth. Collect as many stars as possible before the candy reaches Momo.

Controls

Action Desktop Mobile
Cut rope Click & drag across a rope Swipe finger across a rope
Pop bubble Tap the bubble around the candy Tap the bubble
Pause Menu button (☰) in HUD Menu button (☰) in HUD
Restart level ↺ button in HUD ↺ button in HUD

HUD & Screens

  • Level badge — current level number
  • Stars — stars collected this attempt (top center)
  • Main Menu — Continue, Select Level, Settings
  • Level Select — grid of 100 levels with star progress
  • Win / Lose — animated overlays with retry and next level options

Obstacle Types

  • Wood / Stone — solid platforms
  • Ice — slippery surface
  • Spike — destroys the candy on contact
  • Bounce — trampoline pad
  • Bubble — candy floats upward until popped
  • Wind — pushes the candy horizontally

Settings

Access settings from the Main Menu → Settings or the in-game pause menu.

Option Description
Sound Effects Cut, star, win, lose, pop & UI sounds
Music Procedural background music (menu & gameplay)
Vibration Haptic feedback on mobile (when supported)
Visual Effects Extra particles and glow (where applicable)

Settings are stored in localStorage under the key cutrope-settings.

Customization Guide

The game is designed to be reskinned without a build pipeline. Below are the most common customization tasks.

1. Replace Character & Object Sprites

By default, Momo, candy, and stars are drawn procedurally on canvas. You can replace them with PNG images. Place files in img/ and load before starting the game:

// Add before or after game scripts load — call before enterGame() CutRope.loadSprites({ omNom: 'img/momo.png', candy: 'img/candy.png', star: 'img/star.png' }).then(() => { console.log('Sprites loaded!'); });
Sprites are drawn as squares fitting the entity radius. Use transparent PNGs. Recommended size: 256×256 px or larger.

2. Edit or Add Levels

Levels live in js/levels.js. Coordinates are normalized 0–1 (relative to canvas size).

{ id: 1, name: 'My Level', candy: { x: 0.5, y: 0.28 }, omNom: { x: 0.5, y: 0.88 }, anchors: [{ x: 0.5, y: 0.05 }], ropes: [{ anchorIndex: 0, segments: 14 }], stars: [{ x: 0.5, y: 0.54 }], obstacles: [ { x: 0.5, y: 0.68, w: 0.22, h: 0.04, type: 'wood' } ], bubbles: [], winds: [] }

Obstacle types: wood, stone, ice, spike, bounce

Multi-rope example: add multiple anchors and rope entries; use attachToCandy: true to link a rope end to the candy.

Per-level overrides: search for applyLevelFixes in levels.js to patch specific level IDs.

3. Change Colors & UI Theme

  • css/background.css — loading/menu sky and cardboard tones
  • css/screens.css — menu card, buttons, level grid, Momo mascot on loading screen
  • css/typography.css — font colors and title styles
  • css/game.css — HUD, win/lose panels, in-game buttons
  • js/renderer.js — in-game canvas colors (Momo palette, candy, obstacles)

4. Rename the Game

Edit the title in index.html:

  • <title> tag
  • .loading-title and .menu-title headings
  • Loading subtitle and menu tagline text

5. Change Fonts

Fonts are bundled locally in fonts/ and declared in css/fonts.css. To replace them, swap the .ttf files and update the @font-face rules. Fallbacks: Comic Sans MS, cursive, sans-serif.

6. Reset Player Progress

Progress is stored in localStorage. To reset during testing, open browser DevTools console and run:

localStorage.removeItem('cutRopeProgress'); localStorage.removeItem('cutrope-settings'); location.reload();

JavaScript API

The global CutRope object exposes these methods:

Method Description
CutRope.loadSprites(paths) Load custom PNG sprites. Returns a Promise.
CutRope.enterGame(index) Start level by zero-based index (0 = Level 1).
CutRope.loadLevel(index) Alias for enterGame.
CutRope.exitToMenu() Return to main menu from gameplay.
CutRope.getProgress() Returns { unlocked, stars } progress object.
