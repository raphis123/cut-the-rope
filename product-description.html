About This Product

Cut the Rope is a polished HTML5 casual puzzle game. Swipe across ropes to drop the candy into Momo, collect stars, and complete 100 levels across 10 worlds. Includes Verlet rope physics, win/lose animations, procedural audio, and a complete UI.

Key Features

  • 100 Levels — hand-tuned and generated stages
  • Rope Physics — swing, sag, multi-rope puzzles
  • Momo Character — eat, sad and idle animations
  • Obstacles — ice, spikes, bounce pads, wind, bubbles
  • Mobile Optimized — touch controls, weak device scaling
  • Full UI — menu, level select, pause, HUD, win/lose screens
  • Procedural Audio — music and SFX via Web Audio API
  • 100% Offline — local fonts, no CDN, no server required
  • Easy Reskin — swap sprites, edit CSS and levels
  • Save System — stars and level unlock progress

How to Run

  1. Unzip the download folder.
  2. Open index.html in Chrome, Firefox, Safari, or Edge.
  3. Tap Tap to Start! on the loading screen.
  4. Play from the main menu or select any unlocked level.

Note: Works fully offline. No internet connection required.

How to Play

Action Control
Cut rope Swipe across rope (mobile) or drag mouse (desktop)
Pop bubble Tap the bubble around the candy
Pause Menu button in HUD
Restart Restart button in HUD

Goal: Feed the candy to Momo and collect as many stars as possible.

Customization

Replace Sprites

Add PNG files to the img folder and call CutRope.loadSprites with omNom, candy, and star paths.

Edit Levels

All 100 levels are in js/levels.js using normalized 0–1 coordinates.

Change Theme

Edit CSS files in the css folder for colors, buttons, and menus.

Rename the Game

Update titles and text in index.html.

Technical Details

  • Vanilla JavaScript — no framework, no build step
  • HTML5 Canvas 2D rendering
  • Verlet rope simulation
  • Web Audio API for sound and music
  • localStorage for settings and progress
  • Responsive — phones and tablets supported

Browser Support

Chrome, Firefox, Safari, Edge (modern versions). Mobile Safari and Chrome Android supported.
